Google Sheet connection
Every "Save" writes straight to your Google Sheet, one tab per month, laid out to match this form so you can print directly from Sheets too.

One-time setup:
1. Open a blank Google Sheet → Extensions → Apps Script
2. Copy all the code from pest_control_apps_script.gs, paste it in, then Deploy → New deployment → Web app, "Who has access" = Anyone
3. Copy the deployment URL, paste it above, tap Save URL.
External service connection
Separate web app from the one above. Setup: go to script.google.com → New project, paste the code from external_service_apps_script.gs, then Deploy → New deployment → Web app ("Who has access" = Anyone) and paste the URL here. Records go to a new tab ExternalService in the same Google Sheet.
